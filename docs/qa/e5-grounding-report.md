# E5 grounding QA report

Run `npm run qa:e5-grounding` with `OUR_COMPANION_E5_CACHE` set to the same installed local model cache used by the desktop application. The command disables remote model access and emits per-language similarity and latency observations for calibration.

No real-model observations are recorded in this repository yet: the local E5 cache was not available to this checkout. The Phase 0A thresholds are intentionally conservative provisional values, not a claim of production multilingual calibration.
