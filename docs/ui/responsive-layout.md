# Responsive layout

The Panel window uses a 760 px minimum width and 580 px minimum height. At 900 px the sidebar becomes an icon rail; at 760 px it becomes a horizontal top navigation instead of disappearing. The built Electron UI suite captures 760, 900, 1180, and 1440 px states.

The Creation window is resizable with a 480 px minimum width and 560 px minimum height. Its form body is scrollable so the asset stage remains usable on shorter displays.
