# UI Reference Notes

## Confirmed Direction

- Modern dark desktop shell
- Warm handcrafted notebook interior
- Purple as the bridge color
- Home, Discoveries, Journeys and Memories use stronger notebook styling
- Social and Settings retain notebook identity but prioritize operational clarity
- Companion Overlay remains lightweight and transparent
- Motion should be calm, tactile and interruptible

## Reference Authority

The two concept images define visual direction, not exact pixel layouts.

Current runtime screenshots define:

- real window constraints
- current component behavior
- responsive limitations
- existing implementation state

Existing code and tests define:

- accessibility requirements
- reduced-motion requirements
- interaction behavior
- supported application states
