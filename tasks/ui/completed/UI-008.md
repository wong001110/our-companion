## Objective

Replace Chat's inline clear-history confirmation with the existing shared `ConfirmDialog`, using truthful device-wide scope and explicit irreversible-action copy.

## Scope

- Keep the existing Clear history action in the Chat composer.
- Open the shared destructive confirmation dialog with Cancel initially focused.
- State that all stored Chat history on this device will be permanently removed and cannot be recovered.
- Preserve the existing unscoped `window.ourCompanion.companion.clearHistory()` contract.
- Keep displayed messages on failure and expose a localized recoverable error.
- Preserve filtering, search, sending, retention, keyboard, focus, accessibility, busy, and Reduced Motion behavior.

## Out of Scope

- Per-Companion history, character-scoped loading or clearing, and active-Companion switching behavior.
- IPC, preload, services, database, Network, `Presence`, shared motion APIs, dialog CSS, global CSS, or motion-foundation changes.
- Chat layout, composer behavior, auto-scroll, retention, and send-failure redesign.

## Acceptance Criteria

- Clear history opens one shared danger `ConfirmDialog`; no inline confirmation controls remain.
- English and Simplified Chinese copy describe device-wide permanent deletion accurately.
- Cancel and Escape preserve history and restore focus to the opener.
- Confirm uses the existing unscoped clear-history IPC and shows the existing empty state on success.
- Busy state prevents duplicate confirmation and dismissal.
- Failure keeps messages visible, does not imply success, and leaves a recoverable error.
- The 760 px Simplified Chinese dialog fits without horizontal overflow.
- Focused accessibility and Reduced Motion assertions pass with only the reviewer-authorized shared `ConfirmDialog` prerequisite.
