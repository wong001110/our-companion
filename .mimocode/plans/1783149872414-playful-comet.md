# Engine Linking Architecture - Analysis

## Summary

The 15 engine packages in `our-companion` are **stateless pure-function libraries** that are **not directly linked to each other** at runtime. Instead, they communicate through a **monolithic facade pattern** via `AppServices` (the orchestrator) and share state through `DatabaseService` (SQLite).

## How Engines Are Linked

### 1. Orchestration Layer (AppServices)
`apps/desktop/electron/main/services.ts` (1300+ lines) imports functions from 13 engine packages at the module level and calls them imperatively inside method bodies. There is no dependency injection, service locator, or engine registry.

### 2. Cross-Engine Source Dependencies (Only 2)

| Source | Imports From | What |
|--------|-------------|------|
| `action-engine` | `character-engine` | `planPerformanceScript` (performance animation scripts) |
| `character-engine` | `discovery-engine` | Timing re-exports (`getDiscoveryFetchDelay`, etc.) |

**All other 13 engines depend only on `@our-companion/shared`** (types + utilities).

### 4. Autonomous Exploration Loop Flow

The loop in `AppServices.runAutonomousExploration()` chains engines in this exact order:

```
1. pattern-engine::detectPatterns()
   ↓
2. memory-engine::buildInterestGraph()
   ↓
3. curiosity-engine::generateCuriosityTargets()
   ↓
4. discovery-engine::planExploration()
   ↓
5. discovery-engine::runDiscoveryAgents()
   ↓
6. insight-engine::generateInsights()
   ↓
7. insight-engine::selectPrimaryInsight()
   ↓
8. Broadcast to UI via EventBus
```

### 5. Key Architectural Points

- **AppServices** = sole composition root (monolithic facade pattern)
- **DatabaseService** = shared mutable state (all engines read/write through it)
- **EventBus** = in-process pub/sub for UI broadcasts
- **No DI container** - engines are invoked ad-hoc inside AppServices methods
- **Engines are stateless** - no constructors, no lifecycle, no instance state

## Critical Files

- `apps/desktop/electron/main/services.ts` - Core orchestrator (1300+ lines)
- `apps/desktop/electron/main/index.ts` - Electron main process entry
- `packages/shared/src/index.ts` - Central types (1683 lines)
- `packages/action-engine/src/index.ts` - Action engine (imports from character-engine)
- `packages/character-engine/src/index.ts` - Character engine (re-exports from discovery-engine)
