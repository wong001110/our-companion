# Plan: Count Animations Based on Uploaded Asset Path

## Goal
Determine how many animations are currently implemented in the project, specifically those that are based on uploaded asset paths from creation or edit operations.

## Key Findings

### Animation System Architecture
- **Total animations defined**: 28 (in `animationRegistry.ts`)
- **Animations configured for rendering**: 15 (in `animationConfig.ts`)
- **Animations required for creation**: 15 (in `CompanionCreationPage.tsx`)
- **Animations available for editing**: 28 (in `CompanionEditPage.tsx`)

### Current Implementation Status

#### 1. Animations Actually Rendered Using Uploaded Assets
**15 animations** are implemented and rendered from uploaded asset paths:
- Idle_Neutral, Idle_Breathe, Idle_Sleepy, Idle_Sleeping
- Walk_Right, Walk_Left
- Expedition_Return, Expedition_Prepare, Expedition_Leave, Expedition_Present
- Think, Work_Focus
- Talk_Neutral, Talk_Happy
- Listening

These are defined in `createCompanionAnimations()` at `apps/desktop/renderer/src/character/ann/animationConfig.ts:23-40`

#### 2. Animations Available for Upload but NOT Rendered
**13 additional animations** can be uploaded in the edit page but are NOT currently rendered:
- Waiting_Response, Drag_Hold, Drag_Release
- Talk_Thinking, Talk_Concerned
- Walk_Up, Walk_Down, Walk_UpLeft, Walk_UpRight, Walk_DownLeft, Walk_DownRight
- Enter, Leave
- Music_Idle

These are defined in the registry (`animationRegistry.ts`) and listed in `ALL_ANIMATIONS` (`CompanionEditPage.tsx:25-55`) but lack animation configs in `createCompanionAnimations()`.

### Why This Gap Exists
The `CompanionCanvas` component (`CompanionCanvas.tsx:62`) only uses animations from `createCompanionAnimations(assetRoot)`, which returns exactly 15 animations. The other 13 animations are defined but not configured for rendering.

## Answer to User's Question

**Currently implemented (rendered from uploaded assets): 15 animations**

However, the system is designed to support 28 animations total, with 13 additional animations available for upload in the edit page but not yet integrated into the rendering pipeline.

## Recommendation
If the goal is to have all 28 animations work from uploaded assets, the `createCompanionAnimations()` function needs to be extended to include the remaining 13 animations with appropriate frame timings.
